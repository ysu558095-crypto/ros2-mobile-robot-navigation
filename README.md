# ROS2 Mobile Robot Navigation with Devin AI

基于 ROS2 Humble 的实体移动机器人自主导航项目，计划使用 Devin AI 辅助完成系统开发、代码调试和软硬件集成。

## 项目介绍

目前已经有一辆实体移动机器人小车，准备基于 ROS2 开发完整的自主导航系统，实现环境建图、自主定位、目标点导航和自动避障。

希望通过 Devin AI 协助解决 ROS2 各个模块之间的集成问题，并逐步完成真实硬件部署。

## 技术栈

- ROS2 Humble
- Python / C++
- slam_toolbox：二维激光 SLAM
- Nav2：自主导航和路径规划
- AMCL：机器人定位
- RViz2：地图和传感器可视化
- 2D LiDAR、IMU、轮式里程计（计划接入）
- Devin AI：辅助代码开发、调试和测试

## 为什么使用 Devin AI

本项目的主要难点不是单个 ROS2 节点的编写，而是底盘、传感器、SLAM、定位和导航模块之间的集成。

希望 Devin 能够参与代码开发、配置检查、错误分析和自动化测试，减少人工排查时间。
